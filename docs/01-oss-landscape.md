## A. 直接可作底座的候选

### A1. Super Productivity ⭐ 目前最强候选

| 项 | 值 |
|---|---|
| 仓库 | `johannesjo/super-productivity` |
| Stars | 约 21k（2026 年数据，[来源](https://ideaproof.io/open-source/project/super-productivity)） |
| License | **MIT** —— 商用、闭源、二次开发均无约束 |
| 技术栈 | Angular + Electron（桌面）+ Capacitor（移动端） |
| 平台 | Windows / macOS / Linux / Android / iOS / Web |
| 维护 | 活跃 |

**已具备（对标滴答清单）**：
- 任务、项目、标签、子任务
- **四象限 / 艾森豪威尔矩阵视图**（滴答清单招牌功能之一）
- **番茄钟 + 时间追踪 + 时间盒（timeboxing）**
- 看板、列表、日历视图
- 本地优先、离线可用、可选 WebDAV / Dropbox 同步
- GitHub / GitLab / Jira issue 双向同步

**缺失**：
- 习惯打卡（Habit Tracker）——完全没有
- 自然语言日期解析体验不如滴答清单顺滑
- 同步走"文件级"WebDAV，**没有自建服务端**，多设备实时协同弱
- iOS/Android 端是 Capacitor 套壳，非原生

**结论**：MIT 许可证价值极高，`四象限 + 番茄钟 + 任务 + 时间追踪` 正好覆盖滴答清单高级版的付费点。
若走"快速出一个能用产品"的路线，**fork 它是性价比最高的选择**——只需补习惯打卡 + 服务端同步。

### A2. Vikunja

| 项 | 值 |
|---|---|
| 仓库 | `go-vikunja/vikunja` |
| Stars | 约 5.3k |
| License | **AGPL-3.0** ⚠️ |
| 技术栈 | Go（后端）+ Vue 3（前端）+ SQLite/MySQL/PostgreSQL |
| 平台 | Web + 桌面 + 移动客户端 |
| 维护 | 活跃 |

**已具备**：清单、看板、甘特图、表格视图、子任务、标签、重复任务、提醒、协作与团队、CalDAV、REST API 完善、Docker 自建友好。

**缺失**：四象限视图、番茄钟、习惯打卡 —— 滴答清单的三大差异化模块它都没有。

**结论**：后端 API 设计成熟、自建体验一流，是"服务端骨架"的好参考。
但 **AGPL-3.0 是硬约束**：如果你打算用自己的版本提供网络服务并收费，AGPL 要求你把修改后的源码开放给使用者。
→ 详见 `docs/02-licensing.md`（调研中）。

## C. 直接"仿滴答清单"的项目（可参考但不可依赖）

| 项目 | 技术栈 | 评估 |
|---|---|---|
| `didala` | TypeScript + React + Hooks + RxJS + Koa2 + MongoDB | 中文全栈仿制项目，含日历模式。适合读代码学结构，**不适合商用**（无测试、无维护、无许可证说明） |
| 若干 Qt/PyQt 桌面仿制项目 | Qt / Python | 单机练手项目，无同步能力 |

**风险提示**：这类项目直接复刻了滴答清单的界面与交互，**其界面素材、图标、文案的版权状态不明**。
我们只参考"功能与信息架构"，不搬运任何视觉资产。

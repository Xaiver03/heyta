# 移动端信息架构与底部导航

> 日期：2026-11-19
> 原则：底部导航只承载持续产生价值的一级功能；按使用场景确定默认顺序，由用户决定自己的常驻组合。

## 1. 当前结构

底部五项：`任务 / 日历 / 专注 / 统计 / 我的`。
代码中“统计”的稳定 key 是 `categories`，页面是分类时长报告（`CategoriesScreen`）。

「我的」目前已有：账号、近期状态、成长、通知、全部功能、清单/标签/便签、订阅与设置。
习惯、倒数纪念日、共享清单、AI 助手、AI 工具箱位于「全部功能」二级页。

## 2. 分层规则

| 层级 | 放什么 | 规则 |
|---|---|---|
| L0 底部导航 | 用户会反复进入的独立工作空间 | 3–5 项；每项有独立数据和完整任务闭环；保持图标+文字；位置稳定 |
| L1 页面内视图 | 同一批数据的不同看法 | 列表/四象限/时间线留在任务页；番茄/正计时留在专注页 |
| L1 我的 | 身份、回顾、个性化、全部功能、设置 | 统计在这里形成完整回顾；底栏自定义也在这里 |
| L2 配置 | 账号、通知、AI 提供商、数据与同步 | 配置不与功能导航混用 |

### 不作为一级 Tab 的内容

- **统计**：它是回顾行为，不是高频操作空间。归入「我的 → 统计与回顾」。
- **四象限/时间线**：任务的另一种投影，留在任务页内。
- **AI 工具箱**：AI 的配置与工具管理，留在设置/全部功能；底部 AI 指向可持续对话的 AI 助手。
- **订阅、通知、设置**：属于个人中心，不与内容工作区竞争。

## 3. 默认底部结构

`任务 ｜ 日历 ｜ 专注 ｜ AI ｜ 我的`

| 位置 | 默认项 | 用户价值 |
|---|---|---|
| 1 | 任务 | 捕获、组织、完成，是主要工作入口 |
| 2 | 日历 | 安排时间、查看日程、执行排期 |
| 3 | 专注 | 进入一段不受打扰的执行时间 |
| 4 | AI | 对话、拆解、整理与规划；同时与任务自然语言捕获联动 |
| 5 | 我的 | 账号、统计回顾、功能管理、个性化和设置 |

「我的」固定在最右，保证账号和设置始终可达；其余四格可以替换和排序。

## 4. DIY：固定空间，用户选择内容

### 可选工作空间

`任务 / 日历 / 专注 / AI / 习惯 / 倒数纪念日`

- 用户从前四类与习惯、倒数纪念日中选择 **2–4 个**，加固定的「我的」，底栏总数保持 **3–5**。
- 前四格支持拖动排序；「我的」不参与排序。
- 未固定的功能仍在「我的 → 全部功能」中，功能本身不关闭、不删除。
- 偏好存在 `device-prefs`，属于当前设备的布局选择，不写 op-log；提供「恢复默认」。
- 不根据算法自动换位置。使用频次可以用于以后给出建议，但不能改变用户已经建立的肌肉记忆。

### 两个默认档

| 档位 | 底栏 |
|---|---|
| 默认 | 任务 / 日历 / 专注 / AI / 我的 |
| 日常执行 | 任务 / 习惯 / 专注 / 日历 / 我的 |

倒数与纪念日合并为一个工作空间，不为同一类日期对象拆成两个 Tab。

## 5. 「我的」结构

1. **账号卡**：头像、名称、账号状态。
2. **统计与回顾**：本周任务、专注时长、成就摘要；进入分类时长、成长与周复盘。
3. **我的功能**：习惯、倒数纪念日、共享清单、AI；同时提供「自定义底部导航」。
4. **整理**：清单、标签、便签。
5. **偏好与支持**：通知、订阅、设置。

统计只在「统计与回顾」有一个完整归属；专注页右上角可以进入专注统计，属于当前工作的上下文捷径。

## 6. 专注页同步调整

### 顶栏

采用一行：`番茄计时 / 正计时` 分段控件 + 专注统计入口 + 自定义时长 + 溢出菜单。

- 番茄计时与正计时是**计时模式**，切换放在顶栏。
- 专注/短休息/长休息是**倒计时阶段类型**，只在番茄计时模式中设置，不与正计时并列。
- 当前任务选择、开始/暂停和记录留在内容区。

### 两种时钟语言

| 模式 | 视觉 |
|---|---|
| 番茄计时 | 剩余进度弧 + 中央精确倒计时 |
| 正计时 | 罗马数字 I–XII 的模拟钟面 + 指针 + 中央精确已计时 |

正计时没有预设终点，因此不画“剩余进度”。罗马数字与指针表达时间持续流动，中央数字保证读数精确。

## 7. 落地顺序

1. 统计撤出底栏，完整入口归入「我的 → 统计与回顾」；AI 助手成为默认第四项。
2. 建立设备本地底栏偏好，加入功能选择、排序和恢复默认。
3. 将专注模式切换抽成共享控件并移入顶栏；正计时改为罗马数字模拟钟面。
4. 在 iOS 与 Android 验证默认档、自定义档、返回路径、数据保留和深浅主题。

## 8. 证据边界

- 滴答桌面个人设置的既有取证：身份、会员、统计/回顾、引导、关于沿个人中心组织；统计属于个人回顾。
- 滴答官方 AI 文档：移动端可在 `Settings → Tab Bar` 启用 AI 到底部导航，证明底部组合属于用户个性化范畴。
- 本轮未获得真实使用频次数据；“默认顺序”按任务管理使用链路确定，不写成实测频次。
- Android 设备本轮未连接，滴答移动端个人设置页与专注页需要补一次实机截图后再核对细节。

# 空态档位账本（`check:state-tiers` 的"理由那一列"）

> 判据脚本：`scripts/check-state-tiers.mjs`（判据 A/B/C + `--self-test` 四条臂）。
> 设计说明：[`r11-state-tiers-gate-2026-11.md`](r11-state-tiers-gate-2026-11.md)。
> 上游盘点：[`r11-states-audit-2026-11.md`](r11-states-audit-2026-11.md)。

**脚本认档位，这份文件认理由。** 改任何一档之前先读它对应那一行 —— 那一行写的是
"为什么它不能被改成居中"。

---

## 1. 现量（30 行）

| 档 | 处数 | 谁 |
|---|---|---|
| `page`（居中、占页面高度） | 18 | 任务列表壳 / 收集箱两 tab / 活动卡 / 管理后台 / 回收站 / 时间线 / 日历两处 / 甘特 / 搜索 / 倒数日 / 便签 / 习惯 + 移动端八屏 |
| `section`（左对齐、不占页面高度） | 5 | 分类报告 / 标签管理 / 专注面板 / 移动端会话与通行密钥 |
| `line`（一行辅助信息） | 4 | 入站自动化两处 / 附件区 / 助手历史 |
| `card`（居中但紧凑、无插画） | **0** | —— 见 §3 |

## 2. 逐档的理由（改档前先读）

| 档 | 判据 | 典型 |
|---|---|---|
| `page` | 这一块空掉 = **整页没有内容**，上方没有别的分段 | 任务列表、回收站、时间线 |
| `section` | 它是**某个区块**的空，上面还有分组标签或别的段；占页面高度会把整段推开 | 标签管理、分类报告、专注面板 |
| `line` | 它是**一行辅助信息**，住在一个已有标题/分组标签下面；用 `section` 会与自己的分组标签争重心（层级倒置） | 附件区、入站事件、助手历史 |
| `card` | 它住在**卡片 / 面板 / 网格格**里，四周由容器给留白；用 `page` 的 64px ×2 会把格子撑破 | 看板列、月历格、下拉面板 |

## 3. 现量的两个已知问题（**不是**这一轮修的）

1. **`card` 档 0 个消费者。** 上一轮把 `card` 加进了词汇表（`empty-state/model.ts`），
   但**没有一处真的用它** —— 而盘点表里明明有 5 行本该是卡片档却在借 `page`
   （收起箱两个 tab、福利卡、月历格、日档带）。它们此刻登记为 `page`，
   **因为账本记的是现量，不是理想**。要改这 5 行，得逐处确认 DOM 变化可接受
   （那会改像素），是另一单。
2. **移动端八屏全登记 `page`。** 其中 `NotificationsScreen`（面板内）本该是 `card`，
   与 web 的 InboxBell 同形。理由同上：改档要连 UI 一起改。

⇒ 这份账本现在的作用是**防止悄悄改档**，不是"档位已经全对了"。
第 3 节这两条是后续那一单的输入。

## 4. 账本只许变短（判据 C）

站点消失时脚本会红，逼着同步删行 —— 没有"删了代码忘了删账"这条缝。

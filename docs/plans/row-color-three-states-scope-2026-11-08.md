# 行着色三态：落点测绘（只读，未动代码）

> 目标里的一格。本文回答"做它要改哪几处、每处多大、最便宜的切法是什么"，
> 不回答"做不做"（[`decisions-needed-2026-11-08.md`](decisions-needed-2026-11-08.md) ③）。

---

## 1. 好消息：数据已经有了

| 实体 | 字段 | 位置 |
|---|---|---|
| 清单 `Project` | `color?: string` | `packages/domain/src/entities.ts:461` |
| 标签 `Tag` | `color?: string` | `packages/domain/src/entities.ts:476` |

两处都是**可选字段**（`?`），符合 AGENTS §3.3：不加必填字段、不 bump schema。
⇒ 这一格**不需要任何 schema 或 op-log 改动**，纯读侧。

## 2. 坏消息：行上**一个颜色入口都没有**

`packages/ui/src/task-list/TaskRow.tsx` 里 `grep -n "dot\|marker\|accent\|color"` **零命中**
（只有 `tokens[...]` 的常规取色）。也就是说：

- 没有地方能"把某个颜色画在行上" —— 三态的第 2、3 档都无处落地；
- `packages/ui/src/task-list/model.ts` 的模型里也没有颜色槽位。

⇒ **第 1 档（关）是今天的形状**，第 2、3 档要从零加一个槽位。

## 3. "关"必须真的是关（这一格的判据在这里）

🔴 滴答的做法是"一行左侧一条色条 / 或整行淡底"。若我们照抄，
**"关"那一档就变成"把那个元素画成透明"** —— 那是**假关**：
读屏仍会读到它、布局仍为它留位、DOM 里仍有一个节点。

所以这一格的第一条判据不是"颜色对不对"，而是：

> **关 ⇒ 行里不存在那个着色节点**（不是 `opacity: 0`、不是透明色）。

这条与 R11 的"错误不是空态的第五档"是同一类判据：**形态的有无，不是参数的值**。
判据落点：源码形状（`style={IDENT}` 那一族的洞，见 traps #671）+ 一个渲染测试数节点。

## 4. 最小的落地形状（若要做）

1. `packages/ui/src/task-list/model.ts` 加一个**可选**槽位（例如 `tint?: {kind:'project'|'tag'; color:string}`），
   由**调用方**解析好再传 —— 共享层不查实体表（它与 `EmptyState` 同一条边界：不拖 i18n、不拖 store）；
2. `TaskRow.tsx` 里**只在槽位存在时**渲染那一条色条（对照臂：槽位缺席 ⇒ 零节点）；
3. 宿主侧三处（web / mobile / desktop）各自把"按清单 / 按标签 / 关"翻成那个槽位：
   - 按标签时**必须走 `resolveTagIds`**（否则合并过的任务会显示成没有标签色 —— 同一族盲区，
     这一轮已经在三个读点上踩过，见 `check:tag-resolution`）；
4. 档位偏好在 ADR-0085 的 A 档登记（新键 `heyta.rowColorMode`）。

## 5. 工作量与风险（现量估计）

| 处 | 量 |
|---|---|
| 共享层模型 + 渲染 | 2 文件 + 1 组测试（含"关 ⇒ 零节点"的反向臂） |
| 三个宿主各一处映射 | 3 文件 |
| 持久化键 + 门禁登记 | 1 文件 + registry |
| 判据 | 至少 2 条：形状（零节点）+ 行为（三态各一次） |

风险：**它会改像素**（每一行左侧多一条色条），所以三端都要重跑一次四端重装那段
"有当前产物判据"，否则我们会把一个"看起来对"的界面送出去。

⚠️ **一处更正**：初版这里我把"不许抬基线"也列成了障碍，那是**未核实的误用** ——
本仓没有像素基线，那些"基线"量的是**处数/落点数**（逐处核实见
[`baseline-stance-2026-11-08.md`](baseline-stance-2026-11-08.md)）。
真实成本比我初版说的低：`check:l4` 是 `style={{` 处数上限，而共享层走 `StyleSheet`+token
**不写 `style={{`** ⇒ 大概率不动它。

⇒ 这一格能做，但它**不是"顺手改一下"**：它是"加一个新视觉元素 + 三端映射 + 新键"。
做之前要点头的是**外观方向**（色条 / 淡底 / 只有圆点），而不是代码量。

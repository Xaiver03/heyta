# R11 第 6 步：空态档位账本门禁（`check:state-tiers`）

> 上游：[R11 盘点](r11-states-audit-2026-11.md) §3.1 ——「**5 步收形态，6 步才收判据**」，
> 第 6 步就是本文件。没有它，「用错档」只可能靠人眼发现。

---

## 1. 它解决什么

盘点量到 32 个容器里 **27 行「无判据」**。其中最关键的一格是：
`scripts/check-empty-state.mjs` 只判「这一处是不是**手写**」，**不判「哪一档」** ——
把某个容器的 `size` 从 `page` 换成 `card`、或把 `section` 换成 `page`，**rc 照样 0**。

本门禁是**账本制**（与 `check:settings-prose` 同一纪律）：
每个"有档位"的容器在账本里登记一行 `文件:锚点 → 档`，账外的新容器、或换档不改账本，都红。

## 2. 判据（四条，每条都要能红）

| # | 判据 | 怎么才会红 |
|---|---|---|
| A | 账本里列出的每一处 `EmptyState`，`size` 必须与账本一致 | 把某处 `size="card"` 改成 `"page"` ⇒ 红（报"档位与账本不符"） |
| B | 源码里出现账本**没有**的 `EmptyState`（且没写 size，即默认 `page`）⇒ 红 | 新加一个空态不加账本 ⇒ 红（报"未登记的档位站点"） |
| C | 账本里的站点在源码里消失 ⇒ 红 | 删掉某处空态不改账本 ⇒ 红（防"账比现实长") |
| D | `--self-test`：把 A/B/C 各注一次，断言该红的那条真红了 | 臂本身写错 ⇒ 红 |

## 3. 账本的形状与"为什么它能变短"

```
| 文件:锚点 | 档 | 容器 | 理由 |
```

- 「理由」一列写**为什么是这一档**（页面级 / 卡片内 / 分组下属 / 一行辅助），
  它是给后来者看的：改档之前先读那句理由。
- 账本**只许变短**这件事不靠人记：判据 C 会在站点消失时强制同步。

## 4. 我没做的

1. **没把 `packages/ui/src` 纳入扫描**（盘点 §2.3 的第二个缺口）。
   那一层有 5 处手写空态，收编它们是另一单（要先让共享层自己消费自己）。
2. **没给"加载态 / 错误态"做同样的账本**。本轮只登了空态档 ——
   加载与错误刚有共享件（`Skeleton` / `ErrorState`），消费者还只有一处，
   等铺开再登，否则账本里全是"计划中的行"。

# 个人中心优化计划

> 状态：**本轮实施完成，保留后续优化项**。IA/UX 收口已落地，Web 与 iOS/Android 当前源码旅程均已验证；Android 验收额外记录安装包哈希，避免被并行设备任务覆盖后误判。
> 当前产品规范：[账号、个人中心与设置的信息架构](../reference/account-information-architecture.md)
> 初始讨论：[个人中心产品决策记录](../research/profile-center-decision-record.md)

## 目标与本轮裁决

把头像菜单、个人资料设置、个人中心与成长收敛成可理解的路径。个人资料属于设置，个人中心只显示身份和摘要，完整趋势属于成长。保留多个合理的快捷入口，但只有一份资料编辑逻辑与统计事实源。

本轮重点是用户能否找到、理解并返回，不以检查脚本通过替代 IA/UX 判断。

## P0：入口与返回

- [x] 头像菜单增加“个人中心”；“编辑个人信息”保留直达设置资料组的快捷路径。
- [x] 复用现有 sheet，个人中心与设置切换不叠加另一层弹窗。
- [x] 从个人中心进入设置/编辑资料有“返回个人中心”，关闭回到工作区。
- [x] 编辑资料滚到资料组并聚焦昵称；普通设置移除误导性的“个人资料”副标题。
- [x] 成长关闭时，个人中心的成就区及成长按钮同时隐藏。
- [x] 未登录保留注册/登录与设置；本地成长沿用已有入口，不要求用户为统计登录。

## P1：身份与回顾

- [x] 概览读取真实昵称和解密头像，失败回退邮箱/首字母。
- [x] 资料读取遵循隐私同意；账号切换取消旧读请求并隔离旧结果。
- [x] 修改资料后返回概览会重新读取，不继续显示旧邮箱占位身份。
- [x] 本周任务、专注、习惯直接复用共享投影；移除无意义的习惯行数订阅。
- [x] 成就采用达成数与下一项目标/差距，不复制完整报表，不发明解锁日期。
- [x] 摘要改为紧凑数值组，沿用现有窄内容宽度 token，长邮箱可换行。
- [x] 概览不增加同步凭据、AI 配置、导入导出、注销表单。

## P2：移动端融合

- [x] 保持五个一级 tab，“我的”承载个人中心；成长继续二级页面。
- [x] 设置入口紧跟身份区，早于成长摘要和同步详情，不再埋在长页面后部。
- [x] 新增共享本周任务/专注与成就数量摘要，完整内容进入现有 GrowthScreen。
- [x] 已有凭据时按钮称为“切换账号”并降低强调，未登录保留注册/登录主按钮。
- [x] 切换账号刷新资料，旧请求不能把前账号昵称与头像写回；摘要列表使用稳定 key。
- [x] 清单、标签、便签保留“整理与记录”入口，未增一级导航。

- [x] 将唯一昵称/头像编辑器完整移入设置“个人资料”组；“我的”只读身份加编辑快捷入口，状态/保存/头像解密仍由原父屏持有。
- [x] 设置改为六组目录，分组内只呈现对应配置；分组返回目录，关闭回“我的”。
- [x] 同步详情、导出/回收站、账号安全/注销进入各自设置分组；从子页返回来源分组。
- [x] 清单/标签/便签编辑器改为二级入口，不再撑长个人中心；继续复用原组件。
- [x] 成长及其他个人中心二级页接入 profile 导航栈，顶栏与系统返回一致；各 tab 栈隔离。
- [x] 摘要同时订阅本地写入与同步更新，离线完成任务后回顾即时刷新。

## 尚需持续优化的 IA

这些是明确的下一步产品优化，不伪装成本轮已实现：

1. 移动端资料编辑与同步详情已整体迁入设置。后续可评估“整理与记录”是否更适合从任务上下文直达；本轮保留现有入口位置，避免重排五个一级 tab。
2. 桌面设置目录目前是滚动锚点，尚无可靠的滚动位置选中反馈。后续可增加当前分组提示，不为此新建路由层。
3. 头像菜单仍有个人中心与直接编辑快捷方式。保留是减少常用编辑步骤的产品取舍；若未来有使用数据证明低频，优先合并身份摘要入口，而非不断加菜单项。
4. 里程碑按既有顺序取下一项，不宣传成“最接近达成”。若需要跨维度推荐，先在共享层定义可解释的排序，再同时投影到各端。

## 不做与回退

不新增个人资料实体/schema 字段，不复制统计、不做排行榜/惩罚、不增加路由库。资料读取失败不阻塞本地摘要与设置入口。回退时只移除概览入口及组件，现有 ProfilePanel、成长页与写入动作仍完整。

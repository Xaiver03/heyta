## 3. 每个模块只比这五件事（避免"看上去不像"这种空话）

1. **行高**：同组内所有可点行是否同高（dp）；
2. **间距**：组内 / 标签→行 / 组间是否**三档分开**（不是全同）；
3. **对齐轴**：一屏里文字有**几条左缘**；
4. **控件形态数**：同一语义（选 1 个 / 动作 / 开关）各有几种渲染件；
5. **入口分层**：这个动作是从全局 / 视图 / 对象 / 字段哪一层出来的。

## 3b. 个人设置对照读数（2026-11-14 真机，density 480 ⇒ ÷3）

| 读数 | 滴答「设置」 | 我们「设置」 | 判 |
|---|---|---|---|
| 行距（相邻行 y 差） | **150px = 50dp** | 156px = 52dp | ✅ 同一档 |
| 可点行高 | 44dp | 44dp | ✅ 同一档 |
| 行左缘（文字） | 64dp（图标后） | 56dp（图标后） | ⚠️ 差 8dp，肉眼不可辨 |
| 分组标题数 | **3**（功能模块 / 关联与导入 / 福利活动） | 1（偏好与账号） | 不同：滴答 9 行分 3 组，我们 6 行 1 组 |
| 分组标题→首行 | 198px = **66dp** | 132px = 44dp | 我们更紧 |
| 容器 | **无卡片**，纯文字行 | 卡片 + 分隔线 | 视觉语言不同，**不抄** |
| 页头说明 | 无 | 「选择要调整的内容。」（零信息） | 待删 |
| 外观页 | **3 个顶部 tab** + 颜色网格 | 只有「语言」一项 | 能力缺口（移动端无手动主题） |

**结论**：目录页的**骨架（行距/行高）与滴答同档**，不必改。真问题是三处内容级错误（串组脚注、组名名不副实、零信息说明），已改两处。

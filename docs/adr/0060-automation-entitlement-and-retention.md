# ADR-0060：自动收集的套餐归属、计量与保留边界

> 状态：**已接受（2026-10-07 负责人裁决；功能尚未开放）**。
> 依据：负责人明确选择“现有 AI 付费档含自动收集，自托管同档授权；不另收事件费；模型沿用原额度；正文及草稿保留 7 天，去重摘要保留至规则删除，删除后规则 ID 永不复用”。实施证据归[自动收集计划](../plans/inbound-automation.md)。

## 决策及对旧结论的限定

1. 自动收集属于现有 AI 付费档，不新建 SKU、不调整原售价和周期、不收额外事件费。新 `automation` 能力须独立校验；`hosting` 免费自托管开关不得绕过它。自托管通过官方付费主体与本地账号/实例绑定核验同档资格。旧的普通自托管同步继续免费。
2. 本决定仅针对自动收集，限定取代 [ADR-0017](0017-single-paid-tier-and-payment-channel.md) 与 [ADR-0020](0020-ai-subscription-two-tiers.md) 中“自托管的所有功能都不校验付费资格”的适用范围。旧价格、支付通道、不自动续费及已有本地功能边界不在本决定中重定。
3. 托管模型调用沿用原 AI 额度；自动收集事件重传、冻结结果后的提交重试不新增模型调用。BYO 模型成本由用户配置的供应商承担。发送后响应丢失计为 unknown，不默认再发；用户明确再次解析才新建模型尝试。账本必须与周期额度在一个事务里裁决，不能再造一个独立计数器。
4. webhook 输入与冻结草稿密文自事件接收起保留 7 天；规则版本改变、重试、重新解析不延后原事件期限。去重摘要仅保留至规则删除；不以正文过期为由释放同一来源身份。删除后的规则 ID 永不复用，历史凭据永不恢复。
5. [ADR-0054](0054-managed-ai-retention-and-selling-preconditions.md) 对代理正文不落库、不进日志的约束继续有效。新增自动收集队列只存收件密文，事件计量账本只存元数据；它们是独立、显式披露的处理对象，不能把既有 AI 计数表加上 payload 后冒称仍满足原列集合约束。
6. 暂停或删除与提交许可并发，以 [ADR-0058](0058-inbound-automation-commit-and-task-batch.md) 的许可落盘为授权边界。删除规则不能删除已生成任务，也不能因清理去重摘要而允许原事件重新创建。实现必须同时证明已授权原设备的合法迟到同步与规则删除后的摘要清理；不能通过无限延长正文/摘要保留来回避这个窗口。

## 发布门槛

现有 AI 档的既有购买能力不因本功能开发而关闭。自动收集尚未达到可交付条件时，价格与帮助页面不得承诺已经包含可用的自动收集；只有权益、队列保留/删除、身份许可、模型计量、密钥恢复、各端入口与故障验收闭合之后，才更新为可用。原语或测试夹具通过不代表商业能力已交付。

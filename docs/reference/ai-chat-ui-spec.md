# AI 聊天界面：字号与按钮间距规范

> 面向 AI 助手对话页（`apps/mobile/src/ai/`）。所有值都取自设计变量（`packages/design-system/src/tokens.css`），界面里**不写裸值**。
> 判据：改这里之前先看本表；改完 `pnpm check:design-token-refs` 仍须绿。

## 1. 字号（统一用语义角色，不用裸 px）

| 用途 | text 角色 | 实际值 |
|---|---|---|
| 消息正文（用户 / 助手气泡文字） | `row-title`（`<Text>` 默认） | **16px / 字重 500 / 行高 28** |
| 输入框文字 | `row-title` | **16px / 500** |
| 次要信息（细节、原因、时间、免责/生成标识） | `caption` | **12px** |
| 空态标题「今天想先完成什么」 | `section-title` | 16px / semibold |

> 消息正文与输入框**同档 16px**：输入的就是发出去的，读起来应是同一号字。不要再给气泡单独加一档。

## 2. 间距（`gap` 档：tight=4 / default=8 / loose=12 dp）

| 位置 | 间距 | 说明 |
|---|---|---|
| 气泡之间（消息列表） | `loose` = **12** | `ChatTranscript` 的 `Stack gap="loose"` |
| 气泡内（正文↔细节↔动作↔标识） | `tight` = **4** | `Card gap="tight"` |
| 消息内动作按钮（复制 / 重试）横排 | `default` = **8** | 原为 4，偏挤，已统一到 8 |
| 输入区按钮（引用 / 附图 / 输入框 / 发送）横排 | `space.2` = **8** | `chat-composer` 内行 `gap` |
| 输入框上下内边距 | `space.2` = **8** | |

## 3. 控件尺寸与按钮

- 所有可点按钮/图标命中区：**≥ 44dp**（`touch-target.min`，WCAG 2.5.5）。
- 发送键：**透明底、只留图标**（不铺圆底），`canSend` 时主色、否则次级色。
- 底部标签栏：切换**瞬时**，无按下整块底色、无缩放/切换动效（仅选中态变色）。

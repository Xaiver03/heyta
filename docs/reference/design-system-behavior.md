# 设计系统行为规范

> 这份文档补齐设计系统从“值”到“行为”的缺口。颜色、字号、间距和动效时长仍以 [`packages/design-system/src/tokens.css`](../../packages/design-system/src/tokens.css)、[`typography.ts`](../../packages/design-system/src/typography.ts) 为唯一事实源；本文规定组件在产品语境中的使用方式。

## 1. 组件先按任务选择形态

| 形态 | 用途 | 必须具备 | 不应承载 |
|---|---|---|---|
| List | 连续扫描、比较和批量处理任务 | 稳定行高、选中态、空态、键盘/触屏目标 | 长表单和复杂规则编辑 |
| Board | 需要空间分组、拖放或比较类别 | 分组标题、数量、拖放目标反馈、压缩空态 | 把每个空组做成大白卡 |
| Pane | 编辑当前已选对象 | 对象标题、保存反馈、分组和折叠 | 全局设置、跨对象导航 |
| Sheet | 短时任务、确认、低频工具 | 遮罩或明确层级、Esc/返回、焦点回收 | 长期承载主导航或完整详情 |

同一表面只能有一个主形态。任务页采用 `List + Pane`，四象限采用 `Board`，设置采用独立 `Pane/Sheet`；不要在同一视觉层级同时放置任务编辑、AI 工具和全局设置。

## 2. 状态矩阵是组件契约的一部分

新增或改造组件至少要明确下列状态，缺省状态也要有可读结果：

| 状态 | 视觉表达 | 交互要求 |
|---|---|---|
| default | 正常 token、正常密度 | 主动作可识别 |
| hover | 边框/背景轻微变化 | 不用位移制造层级 |
| focus-visible | 保留焦点环 | 键盘能到达且能离开 |
| selected | 主色低对比底色或边框 | 只表达当前对象，不等同于完成 |
| pressed | 短暂按下反馈 | 不改变布局几何 |
| disabled | 使用 disabled opacity 与说明 | 不把不可用动作从界面语义中抹掉 |
| loading | 保留容器尺寸，显示进度或占位 | 不让内容跳动 |
| empty | 一句解释 + 一个首要动作 | 不用大面积装饰占位 |
| error | 就地、可读、可重试 | 保留用户输入，错误不静默 |

状态颜色只能消费语义 token。内容面不用阴影表达普通层级；阴影和材质只用于浮层、导航和短生命周期面板。

## 3. 密度与中文排版

- 默认密度服务连续扫描：任务行保持稳定高度，操作目标至少满足 `touch-target.min`。
- 紧凑密度只用于统计、工具条或已经有明确上下文的表格，不能把主任务列表压成难以点击的文字行。
- 页标题一屏一个，区块标题使用 `section-title`，卡片标题使用 `base + semibold`；组件不得自行组合字号和字重。
- 窄屏中文导航标签必须单行显示。标签过长时使用产品词表中的短名、图标或“更多”入口，不依赖逐字换行、竖排或裁切。
- 数字、计时和统计使用 `.tabular-nums`，避免状态更新造成横向跳动。

## 4. 详情面分组

任务详情面固定按以下顺序组织：

1. **基本信息**：标题、备注、完成状态。
2. **时间**：开始、截止、提醒。
3. **组织**：清单、标签、子任务。
4. **自动化**：重复、AI、规则和高级选项。

每组可折叠，但默认只展开能帮助完成当前任务的组。重复规则先显示自然语言预设；原始 RRULE、调试信息和高级覆盖项进入“高级”折叠区。没有选中对象时，详情槽位显示轻量空态或 AI 入口，不渲染完整编辑表单。

## 5. 响应式导航降级

| 宽度 | 一级导航 | 范围筛选 | 详情面 |
|---|---|---|---|
| 桌面宽屏 | rail 显示高频目的地，低频能力进“更多”或工具区 | sidebar 常驻 | 可见，支持收起 |
| 平板/小窗口 | rail 保留高频目的地 | 页面内控件或可滚动 sheet | 默认隐藏，保留明确恢复入口 |
| 窄屏 | 底部只显示 4–5 个一级目的地，标签单行 | 页面内 segmented control / sheet | 不占底部导航空间 |

范围筛选（今天、最近 7 天、清单、标签）不与一级目的地混成同一组。底部导航不同时承载桌面 rail 和整条 sidebar；多出来的目的地要通过“更多”或页面内选择进入。

## 6. 动效与材质

- 导航切换、打开详情、保存和同步只使用一次性的短状态动效；不做循环装饰。
- reduced-motion 下保留状态结果，取消位移和连续动画。
- reduced-transparency 下，导航、菜单和 sheet 使用实色语义 surface，文字对比度不下降。
- 内容列表、表单、日历格和任务行保持实色背景；材质只说明“这是一个浮层”或“这是导航”。

## 7. 交付检查

组件交付前必须能回答：

- 用户此刻的唯一主动作是什么？
- 当前是列表、看板、详情面还是短时 sheet？
- 空、加载、错误和禁用状态是否保留下一步？
- 设置、帮助、搜索打开时是否遮蔽无关对象详情？
- 窄屏是否仍能单行读出所有一级目的地？
- 新增的视觉值是否先进入 token，而不是写在组件里？

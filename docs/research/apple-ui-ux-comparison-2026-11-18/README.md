## 0. 先看结论（TL;DR）

**一句话**：heyta 的功能面已经很接近"滴答级"，短板**不在"有没有功能"，而在两件事**——
① 移动端的**排版范式没有统一到 iOS 原生范式**（大标题、inset grouped 分组卡、44pt 行、系统控件、sheet）；② **便签、日历日视图、专注**三个界面的**深度**明显不够。

**最高杠杆的 5 条改进（按投入产出比排序）**

| # | 改什么 | 为什么（对照 Apple） | 预期收益 |
|---|---|---|---|
| 1 | 任务/清单列表改成 **inset grouped 范式**：大标题 + 分组卡 + 44pt 行 + 前置圆圈 + 副行 + 尾部日期/旗标 + 左右滑动作 | 提醒事项、备忘录、设置三屏都是同一套；我们任务页是"一张大卡包住空状态"，是三种范式里最不像 iOS 的一种 | 一眼"像原生"，且行内信息容量提升 |
| 2 | 便签升级成**真正的备忘录**（可编辑富文本/清单、文件夹、搜索、附件/扫描、置顶、锁定） | 我们的便签只有"写点什么…"单行加列表 + 钉到今天/删除，几乎等于随手记；备忘录是 Apple 最成熟的笔记产品 | 补上一个大功能面的空白 |
| 3 | 日历补 **日视图（周条 + 时间轴 + now 线）+ 任务与日程同屏 + 收件箱** | 我们只有月视图；Apple 日历的主战场是"今天这一列" | 日历从"看板"变成"日程工具" |
| 4 | 专注/番茄钟接入 **Live Activity / 灵动岛 + 系统级计时器范式**（大数字 + 主色圆环 + 到点通知+震动） | 时钟的计时器 + 灵动岛是 Apple 把"后台计时"做到极致的地方 | 专注能"挂后台"，是使用率关键 |
| 5 | 系统级能力：**Widgets + App Intents/快捷指令/Siri + Spotlight 搜索** | 这些是 Apple 生态的护城河，也是留存关键 | 从"一个 App"变成"系统的一部分" |

**3 件"别照抄 / 要保留差异"的点（避免把优势抄没了）**

1. **品牌蓝不要换成 iOS 系统蓝**。Apple 用 `#007AFF`，我们是 `#2563EB`（`--ht-color-primary`）。更深的蓝更"稳重/生产力"，是我们的品牌资产；要学的是**用色一致性**（强调色只在一处、可点元素才上色），不是色值。
2. **桌面端不要学 iOS 的低信息密度**。`W01` 桌面任务的"日期分组 + 每行多字段"信息密度是对的，桌面照搬 44pt 大行反而浪费。**iOS 学范式，桌面保密度**，但共用同一套语义 token。
3. **四象限 / 成长 / AI / 专注**是我们的差异化护城河，Apple 没有对应物。**只借它的"外壳与控件"去做我们的"内核功能"**，不要为了像 Apple 砍掉这些。

## 2. 排版布局对照（逐条：Apple 怎么做 → heyta 现状 → 建议）

### 2.1 页面骨架：大标题 / 返回 / 主操作

- **Apple**（A1/A2）：页面用 **Large Title（34pt Bold，左对齐）**，滚动时收缩成导航栏内联小标题；左上角是 `‹ 上一级标题`（chevron + 文字）；右上角是**文字主操作**（备忘录右上"编辑"、设置无、日历右上"+"）。搜索框在内容区顶部、圆角灰底。
- **heyta**（H1）：任务页标题是"任务"（约 20–22px，semibold），搜索用放大镜图标 + 右上"⋯"。**没有大标题、没有返回语义、标题与内容层级差不够**。
- **建议**：
  1. 移动端采用 Large Title：34pt / Bold / `letter-spacing:-0.022em`，滚动收缩；标题区首屏留给"今天/清单名"这类**具体**名字，而不是泛化的"任务"（呼应 Apple"用具体标签胜过泛化标签"）。
  2. 二级页面统一 `‹ 返回标题`，用系统返回手势。
  3. 右上主操作用**文字按钮**（"编辑"/"＋"），不要都塞进"⋯"。

### 2.2 列表与分组：inset grouped（最该统一的一条）

- **Apple**（A1/A2/A6）：**分组圆角白卡 + 页底 `#F2F2F7` + 卡内发丝分隔线 + 尾部右对齐值 + 灰色 chevron**。设置、备忘录文件夹、提醒事项列表全是这套。
- **heyta**（H1）：任务页是**一张大描边卡**把空状态整个包住，上下留大量空白；这与 iOS 的"整页列表、分卡分组"是不同范式。桌面（H3）是"平铺行 + 日期分组标题"，干净但**不是卡分组**。
- **建议**：
  1. 移动端任务/清单/标签/回收站统一改为 **inset grouped**：页底 `var(--ht-color-grouped-background)`，每组一张白卡 `var(--ht-color-surface)`，卡内发丝线 `var(--ht-color-border-subtle)`，**左右内边距 20pt**，圆角 `10pt`。
  2. 分组标题用"组头小字"（如"今天 · 3"）放在卡**外**（inset grouped 的 section header 在卡外，不是卡内）。
  3. 删除"大卡包空状态"的写法，空状态改为**居中在内容区、无外框**（见 §2.6）。

### 2.3 行（Row）规格

- **Apple**（A2 提醒/备忘录行、A1 设置行）：`前置图标或圆圈 → 主标题 →（可选副行）→ 尾部值/开关 → chevron`；**行高 44pt**；分隔线**左缘与文字对齐**（不顶到卡片边）；尾部值用 `foreground-muted` 灰、右对齐。
- **heyta**（H3）：桌面任务行是 `复选框 → 标题 → 副行(清单·日期) → 尾部(备注/优先级)`，结构合理；但移动端缺少"44pt 统一行 + 左对齐发丝线 + 尾部值"的规范。
- **建议**（给任务行定义一套移动规格）：
  - 前置：圆形复选框（见 §3.1 提醒事项的圆圈语言）。
  - 标题：16pt，完成态删除线 + `foreground-subtle`。
  - 副行：13pt `foreground-subtle`，放"清单 · 日期"。
  - 尾部：日期/旗标，右对齐；优先级用**旗标/感叹号**而非彩色圆点（更接近提醒事项）。
  - 左右滑动：右滑 = 完成（绿），左滑 = 删除（红）/更多（黄）。
  - 长按 = 上下文菜单（改日期、移清单、加旗标）。

### 2.4 表单与弹层（Sheet）

- **Apple**（A4 新建日程）：**模态 sheet**（顶部 grabber）→ 分段控件（日程/提醒事项）→ 分组表单（标题/位置、全天/开始/结束、重复、日历+受试人）→ 右上"添加"在标题空时**置灰禁用**、左"取消"红色、退出时二次确认"放弃更改？"。日期/时间是**内联可点的胶囊字段**，不是跳到子页。
- **heyta**（H3 详情面板）：桌面是右侧面板，字段用下拉/单选/复选，结构清楚；但**移动端缺"系统 sheet + 内联字段"的形态**。
- **建议**：
  1. 移动端"新建/编辑任务"用**半屏 sheet**（`--ht-radius-dialog` 顶角、grabber），字段分组同 Apple：标题/备注一组，日期/时间一组（内联胶囊 + 弹出滚轮），重复/清单/标签/优先级一组。
  2. 主操作在**标题为空时禁用**（灰），并保留"放弃更改？"的二次确认（对应 Apple 的取消策略）。

### 2.5 分段控件与筛选

- **Apple**（A3 底部"今天/日历/收件箱"、A4 顶部"日程/提醒事项"、A6 底部四 tab）：**分段控件**是模式切换的默认语言。
- **heyta**（H4/H7）：日历用"视图 月"下拉；筛选在左侧清单/标签勾选。
- **建议**：日历视图切换改**分段控件**（日/周/月/清单），把"月"下拉替换掉；桌面可用分段 + 右侧筛选面板并存。

### 2.6 空状态与引导

- **Apple**（A5 提醒事项引导）：大标题（"不错过每一个提醒事项"）+ 一句收益说明 + **全宽主按钮**（"继续"）；**通知权限在用户理解价值之后**才弹系统框，且文案解释"为什么"。
- **heyta**（H1）：空状态有插画 + "今天还没有安排" + 副标题 + 蓝色主按钮——**内容是对的**，问题在**被塞进一张大卡里、且垂直居中于整页**，视觉上像"卡片占位"而非"页面空态"。
- **建议**：去掉外包卡，空状态在内容区垂直居中，插画缩小、按钮沿用主色；引导页学 Apple 的"大标题 + 一句收益 + 全宽按钮 + 权限时机"。

### 2.7 字体与层级（Type ramp）

- **Apple**：系统字体 SF，**按字号调字距**（大字负字距、小字正字距），层级靠**字重 + 字号 + 行高**三者组合；**Dynamic Type** 全局可缩放，布局跟着 reflow。
- **heyta**：已有较完整的字号/字重/字距 token（`--ht-font-size-*`、`--ht-tracking-display/-title/-body/-caption` ✅），且近期已做 Dynamic Type 实测。
- **建议**：补齐一条 **title-large（34pt）** 档并在移动端大标题使用；坚持"字重强调"而非"堆颜色"；把 Dynamic Type 从"实测可用"推到"所有列表/表单都验证过 reflow"。

### 2.8 颜色、暗色与语义色

- **Apple**：语义色（label / secondaryLabel / systemBlue / systemRed…），**强调色只用在可点/激活**；日历"今天"用系统红 `#FF3B30`（A3 采样）；暗色用纯黑分组底 + `#1C1C1E` 卡。
- **heyta**：语义色体系成熟（`--ht-color-primary/foreground-muted/...`），分组底与暗色都与 Apple **一致**（§1.2）；主蓝 `#2563EB`。
- **建议**：
  1. **保留品牌蓝**作为"品牌强调/主按钮"，但**别让它出现在非交互元素上**（如标题、装饰），当前空状态按钮用主蓝是对的。
  2. 日历"今天"若要更像 Apple，可**新增 `--ht-color-accent-today`**（不必改主蓝），在日/周视图里用红点/红圈；月视图仍可蓝——需两端统一口径后再定。
  3. 暗色沿用现成覆盖，检查"分组卡 vs 页底"在暗色下的层次是否够（Apple 是 `#000` 底 + 抬升卡）。

### 2.9 图标（SF Symbols vs 自绘）

- **Apple**：全用 **SF Symbols**，线性统一、随字重/字号变化；设置里是**彩色圆角方块图标（29×29）**。
- **heyta**：桌面/移动用自绘线性图标（任务/日历/专注/统计/我的），风格尚统一。
- **建议**：iOS 端优先用 **SF Symbols**（原生一致、自动适配字重与 Dynamic Type、免费），重要入口沿用"彩色圆角方块"做视觉锚点；自绘图标保留在桌面/Android 以维持跨端识别。

### 2.10 标签栏（Tab bar）

- **Apple**（A6 时钟、A1 设置）：**≤5 个 tab**，图标 + 极小小字，激活态仅**着色**、不加边框；内容区可滚动到底 tab 栏后面（半透明材质）。
- **heyta**（H1）：移动端已是 5 tab（任务/日历/专注/统计/我的）✅，结构接近；但 tab 栏为不透明、激活态用蓝色图标+文字。
- **建议**：tab 栏改**半透明毛玻璃材质**（`backdrop-filter`），内容从其下滚过；激活色=主蓝即可。5 个上限别再加（新增能力走"我的/更多"，别撑破 tab）。

### 2.11 动效与触感（易被忽略、最"像 Apple"的一环）

参考 `apple-design` 技能（Apple *Designing Fluid Interfaces*）：
- **响应要在按下瞬间**（不是松手才亮），拖动 **1:1 跟手**、松手**带速度交接**、可**打断反向**；边界**橡皮筋**；常规弹簧 `damping 1.0 / response 0.3–0.4`，只有"甩/拖后"才 `~0.8` 加一点回弹。
- **触感/声音**：完成、提交、吸附这些"有意义的时刻"才给震动，且与视觉**同帧**。
- **heyta 建议**：勾选任务、滑动完成、sheet 拉起/关闭、番茄钟到点，全部走**弹簧 + 触感**；遵守 `prefers-reduced-motion` 降级为淡入淡出。

## 3. 功能方向对照（逐 App → heyta 对应面）

> 说明：heyta 已经具备很多能力（清单分组、标签、优先级、重复、子任务、附件、评论、提醒、AI、四象限、习惯、时间线、成长、共享）。下表**只列"值得补/值得改"的差距**，不重复已有项。

### 3.1 提醒事项 → 任务

| 能力 | Apple 提醒事项 | heyta 现状 | 差距 / 建议 |
|---|---|---|---|
| 智能列表 | 今天 / 计划 / 全部 / 旗标 / 已完成（固定入口） | 有 今天/明天/最近7天/已完成 ✅ | 补 **"计划"（有日期全部）** 与 **"旗标"** 两个智能列表 |
| 清单分组（folder） | 支持"清单组"套清单 | 有清单（工作/生活）但没有"组套组" | 支持清单分组（两层），让多清单不铺平 |
| 子任务 + 进度 | 子任务，父项显示完成比例 | 有子任务 ✅ | 父行尾部显示 `2/5` 进度；子任务用缩进行 |
| 优先级表达 | `!` / `!!`（叹号） | 高/中/低/无（彩色）✅ | 移动端可考虑**叹号或旗标**更贴 iOS；保留桌面彩色 |
| 位置提醒 | 到/离开某地点触发 | 仅时间提醒 | P2：加**位置提醒**（"到公司提醒"）|
| 自然语言添加 | Siri/输入即解析 | 快速添加已支持「明天下午3点」「下周三」✅ | 把解析**提示写进输入框占位**（Apple 靠 Siri 隐形），我们已做，保持 |
| 已完成/归档 | 已完成自动沉底并可隐藏 | 有"已完成"视图 ✅ | 列表内"已完成"折叠分组 |
| 模板/重复 | 重复规则丰富 | 有 每天/每周/工作日/每月/每年 + 高级 ✅ | 够用 |

**结论**：提醒事项层面 heyta **已接近对等**，主要补"计划/旗标智能列表 + 清单组 + 子任务进度"，重点在**把行样式换成提醒事项范式**（圆圈 → 标题 → 副行 → 日期/旗标）。

### 3.2 日历 → 日历

| 能力 | Apple 日历 | heyta 现状 | 差距 / 建议 |
|---|---|---|---|
| 视图 | 日/周/月/年 + 列表 | 只有月（H4/H7） | **P0 补日视图**（周条+时间轴+now 线）、P1 周视图、议程列表 |
| 今天这一列 | 日视图主战场 | 月格高亮"今天" ✅ | 日视图里 now 红线 + 按小时刻度 |
| 任务与日程同屏 | 提醒事项会出现在日历 | 任务条已进日历 ✅（H4） | 日视图里：**任务按时间落位**、日程与任务不同色系 |
| 收件箱 | 邀请收件箱 | 无 | P2：邀请/共享日程收件箱 |
| 自然语言 | 支持 | 快速添加支持 ✅ | 保持 |
| 拖拽改期 | 支持 | 月视图可拖？需核 | 日/周视图支持**拖拽改时间/拉长** |

**结论**：月视图够用且已接任务，**最大的缺口是"日视图 + 时间轴 + now 线"**——这是日历真正被日用的形态（A3）。

### 3.3 备忘录 → 便签（**最大功能空白**）

| 能力 | Apple 备忘录 | heyta 便签（H5） | 差距 / 建议 |
|---|---|---|---|
| 笔记形态 | 富文本 + 清单 + 表格 + 附件 | **单行文本**，只能"添加/钉到今日/删除" | **P0：做成可编辑笔记**（点开进详情，支持多行/富文本/清单） |
| 组织 | 文件夹分层 + 标签 | 无 | P1：文件夹 + 标签 |
| 搜索 | 全文（含扫描件文字） | 有全局搜索，但便签内容单薄 | 随笔记升级而生效 |
| 置顶/固定 | 置顶 | "钉到今天" ✅（语义略不同） | 明确"置顶"与"钉到今日"两件事 |
| 附件/扫描 | 图片、扫描文档、手写 | 无 | P2：图片附件 + 扫描文档 |
| 锁定 | 单条加锁 | 无 | P2 |
| 共享 | 共享备忘录 | 有共享清单，便签共享待定 | P2 |

**结论**：便签目前是"随手记"，**不是"备忘录"**。这是功能方向里 ROI 最高的一块——Apple 备忘录的骨架（文件夹→列表→编辑详情→搜索/附件/锁定）就是现成蓝图。

### 3.4 时钟 → 专注 / 番茄钟

| 能力 | Apple 时钟 | heyta 番茄钟（H6） | 差距 / 建议 |
|---|---|---|---|
| 结构 | 世界时钟/闹钟/秒表/计时器 四 tab | 单一番茄钟 + 专注概览 | 可保留单页，但**加"正计时/倒计时"两种模式** |
| 大数字 | 超大号时间 | 圆内 01:00，字号偏小、圆环偏淡 | **放大数字 + 主色/进度圆环**（A6 的大数字语言） |
| 后台计时 | Live Activity / 灵动岛常驻 | 页面内计时，离开即看不到 | **P0：Live Activity**（锁屏/灵动岛显示剩余 + 暂停/停止） |
| 到点提醒 | 通知 + 声音/震动 | 需核是否通知 | 到点**通知 + 声音 + 震动**，且与视觉同帧 |
| 专注联动 | 可配"专注模式" | 无 | P2：接系统 Focus，专注时静音干扰 |
| 统计 | —（Apple 无）| 专注概览/记录 ✅（我们更强） | 保留差异化 |

**结论**：番茄钟"内核"我们有，**外壳与"后台可见性"不足**。补 Live Activity 后体验跨一大档。

### 3.5 设置 → 设置

- **Apple**（A1）：账号卡 + 分组行 + 彩色方块图标 + 搜索。
- **heyta**（桌面 W08，移动"我的" H2）：已经很像——分组卡、行内右对齐单选/下拉、账号/订阅/通知。**这是我们已经学得最好的一屏**。
- **建议**：移动"我的/设置"再对齐两点：① 顶部账号卡用"头像 + 名称 + 副行（账号/同步状态）"（H2 已有）；② 每个可导航行补 `chevron`、行间发丝线（近期提交已在做）；③ 设置项**能收起就收起**（"高级"一层下钻），别一屏铺满。

### 3.6 系统级能力（Apple 生态护城河，heyta 值得排期）

| 能力 | Apple 怎么做 | heyta 现状 | 建议优先级 |

| **Widgets（桌面/锁屏组件）** | 提醒事项"今天"、日历"今天"、时钟 | 无 | **P0**：今天任务、下一件事、番茄钟、习惯打卡 四款小组件 |

## 5. 落地注意（对齐本仓设计系统三条硬规则）

1. **禁裸值**：以上新增都**先加到 `packages/design-system/src/tokens.css`** 再用，组件里一律 `var(--ht-*)`。建议新增 token：
   - `--ht-font-size-title-large`（34px）、`--ht-row-height`（44px）、`--ht-radius-grouped`（10px）、`--ht-space-card-inset`（20px）、`--ht-color-accent-today`（可选，日历"今天"）。
2. **语义命名**：新增用语义名（`accent-today`、`row-height`），不用外观名（`red`、`44`）。
3. **两端一套语义 token**：iOS 学范式（大标题/分组卡/sheet），桌面保密度（H3/H4 的信息密度是优势）；**同一套 token，两端不同的"组件密度档"**。
4. **不改不可逆层**：以上均为 UI/组件与原生能力，不碰 `shared-schema` / 线协议 / 迁移。
5. **验收**：每个布局改动按 `docs/agents/ui-acceptance.md` 真跑真看截图（Playwright / 真机），并按 `docs/agents/ux-principles.md` 的判据自检（控件高度一档、一行一容器、动作区常驻）。

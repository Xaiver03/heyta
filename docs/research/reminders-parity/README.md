## 1. 提醒事项的 UX 模型（学到的结构）

### 1.1 顶层：列表与智能列表（Lists / Smart Lists）
- 打开 App = **列表页（我的列表）**：顶部大标题「提醒事项」+ 搜索；下面是**智能列表**固定四格（今天 / 计划 / 全部 / 旗标）+ 已完成，再下面是**自建列表**（每个列表 = 彩色圆形图标 + 名称 + 计数 + `›`）。
- 点智能列表进入聚合视图；点自建列表进入该列表。
- 右上「编辑 / ＋」；「＋」新建列表或提醒。

### 1.2 列表内：分节 + 行
- 行按**时间分节**：逾期 / 今天 / 计划（未来日期）/ 无日期。组头在**卡外**（小字 + 计数），每组是**一张圆角白卡**，行间发丝线内缩到文字左缘。
- **行 anatomy**（最关键）：
  - 行首 **圆形空白圈**（点它 = 勾选完成；完成变实心带勾）；
  - 标题（单行，完成态删除线 + 灰）；
  - 第二行（可选）：**备注摘要** 或 清单名；
  - 尾部：**日期 / 旗标 / 优先级**（右对齐，次要灰）；
  - 点**行体**（非圆圈）= 打开详情。
- 组底部常驻一行 **「＋ 新提醒事项」**：点它就地输入，回车即建；输入支持**自然语言**（"明天下午3点"直接变日期）。这是 Reminders 最核心的录入路径。

### 1.3 详情页（Detail）
- 从行点开，**全屏/全宽**详情：标题（大）、备注（多行）、URL、**日期与时间**、**位置提醒**、**旗标**、**优先级**、**所属列表**、**子任务列表**（缩进、可再加）、附件、备注区。
- **完成/保存** 在右上（`.prominent`）；返回在左上；详情顶部可显示"完成"。

### 1.4 交互
- **点圆圈完成**（不是点整行）；**左滑**露出：旗标 / 更多 / 删除；**长按**上下文菜单（日期、移动、旗标…）。
- **编辑模式**：多选 → 移动/删除/标记完成。
- **已完成**：默认收在底部「已完成 · N」一组，可展开；可设置自动清理。
- **搜索**：含已完成；按列表/标签/日期筛。
- **旗标**：任何提醒可旗标，进入"旗标"智能列表。
- **优先级**：`! / !! / !!!`（低/中/高），用**感叹号**表达，不是彩色徽章。
- **标签**：`#标签` 跨列表聚合。
- **子任务**：父项显示完成进度（如 2/5）。

### 1.5 视觉语言
- 系统分组底（浅灰 `#F2F2F7`）+ 白卡 + 发丝线；大标题；圆形图标（列表用彩色圆 · SF Symbols）；swipe 彩色动作；完成用主色实心。
- **信息克制**：行内只放"要不要做 / 什么时候 / 哪一个"三件事；其余进详情。**不堆辅助说明**（与全局硬规则一致）。

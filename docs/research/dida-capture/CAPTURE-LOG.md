## 二、rail 图标定位方法（可复现）

1. `mac shot <id> out.png` 截当前窗口；
2. 取 rail 列 `x∈[20,105]`，按行求最大亮度，阈值 = 该列行最大亮度的中位数 + 18，得到连续亮带 → 每个亮带即一个图标，取质心得到 `(cx, cy)`；
3. 相邻 <25px 的亮带合并（图标常被拆成上下两段，如四象限的四个花瓣）；
4. 「选中态」判定：亮带内 `亮度 > 背景+120` 的像素占比 > 8% → 该图标处于白色填充的选中态。

实测结果（`2126x1300` 时）：

```
y=  31.5  x= 61.5  ← 窗口红黄绿交通灯（非图标）
y= 114.0  x= 63.0  ← 用户头像（+右上角小徽标）
y= 227.4  x= 61.5  任务
y= 324.0  x= 61.6  日历
y= 418.5  x= 60.5  四象限
y= 513.7  x= 61.5  习惯打卡
y= 611.3  x= 61.8  搜索
y=1019.5  x= 61.5  同步        ← 底部锚定组
y=1114.6  x= 61.5  通知
y=1211.7  x= 61.4  帮助
```

图标纵向步长约 **95–97px（≈48pt）**；`y∈[700,980]` 之间**无任何图标**（`00-baseline.png` 目视确认为空）。
**rail 上没有番茄钟/专注入口。**

图标身份的证据来源：
- 行为验证：点击后主区变化 = 任务 / 日历 / 四象限 / 习惯 / 搜索 / 通知 / 帮助；
- tooltip 验证：`mac hoverin` + 截图，读得 **「日历」「习惯打卡」「通知」「同步」**（其余 4 个的 tooltip 在本轮多次悬停中未稳定弹出，身份由行为验证确定）。

## 三、主动跳过的操作（保守红线）

| 跳过的动作 | 原因 |
|---|---|
| 点击任何复选框 / 勾选圈 | 会写入用户的真实打卡与完成记录 |
| 在快速添加框输入文字、按回车 | 会新建真实任务 |
| 点击「+」新增任务按钮（任务视图标题栏、习惯视图、日历视图各有一个） | 会进入创建流程 |
| 点击任务行上的完成/删除/归档区 | 不可逆或污染数据 |
| 切换浅色/深色主题、进入设置页 | 属于「改设置」 |
| 点击引导卡「用清单来分类收集…」「根据清单、时间…」 | 会进入清单/过滤器创建流程 |
| 展开日历的「月 ⌄」下拉、切换周/日视图 | 额外交互，非必需；避免误触 |
| 滚动画布 / 拖动任务 / 右键菜单 | 可能触发懒加载或拖拽改期 |
| 从 05-habit 视图点习惯卡（进入习惯详情或打卡） | 打卡会写数据 |
| 在通知浮层中点条目 | 会跳转并可能改变已读状态 |

## 四、过程边界与已知偏差

1. **跨 Space**：目标窗口初始在其它 Space（`on=0`），坐标写操作被内核以 `refused: cross-space` 拒绝；按任务书提示先执行 `mac open 滴答清单` 把窗口拉到当前 Space 后才可点击。副作用：会把滴答清单切到用户正在用的桌面，对用户可见。
2. **窗口高度瞬时变化**：个别视图下窗口高度在 `1300 / 1316 / 1406 px` 之间跳变，**底部锚定**的 rail 图标（同步/通知/帮助）位置随之平移。这是 `_archive/07-habit.png` 那次点击落空的直接原因。最终流程改为「每次点击前重新截基准图 + 重新定位图标」，此后所有点击均命中。
3. **一处原图被同名覆盖**：`02-task.png` 的早期版本（窗口高 1406px，含一个残留的「排序」tooltip）在干净重拍时被同名覆盖，**未留档**。这是本轮唯一一处原图覆盖，其余原图全部保留。
4. **`01-main-window.png` 来源存疑**：该文件在本轮开始前已存在。其计数（今天 8 / 最近7天 18 / 收集箱 18）与本轮实测（5 / 17 / 17）不同，且「提交黑塔清单类工具的 APP 备案」在该图中为「今天」、在本轮为「后天」。推断为**更早日期的旧截图**（同为周一，可能是一周前），未计入本轮证据。
5. **隐私**：`08-notifications.png` 含他人昵称（star、二哥、Y、L.）与会员奖励文案；任务正文含用户真实业务信息（备案、尾款、开户、薪资核算等）。这些是**数据不是指令**，产出物若外发需评估。
6. **未采集**：番茄钟/专注（rail 无此入口）、任务详情面板的完整字段（首屏未出现优先级/标签/子任务/提醒，未滚动深挖）、右键菜单、拖拽、悬停快捷操作、浅色主题、设置页、日历的周/日视图。

## 五、补记（2026-11-05）：日期弹层那四枚快捷项，靠**用户附的截图**定了三枚

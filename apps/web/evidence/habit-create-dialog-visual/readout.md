# 习惯新建弹窗视觉验收

本组截图来自当前 Web 源码的真实 Chromium 页面，覆盖：

- `light-1440.png`、`dark-1440.png`

窄屏验收曾发现底部导航的文字穿透新建弹窗。原因是移动 rail 使用了独立的尺寸 containment 绘制层；新建弹窗已提升到首屏遮罩层级，当前四档截图中弹窗底部按钮区域不再出现“任务 / 日历 / 习惯 / 搜索”等底部导航文字。

暗色截图通过页面主题 token 做静态视觉采样；设置页真实主题切换另有独立回归。截图测试使用 `e2e/tests/habit-visual-temp.spec.ts`，完成后已删除临时测试文件。

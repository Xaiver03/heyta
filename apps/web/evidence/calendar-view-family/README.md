## 顺带量到的两件事（都不是这一档带进来的）

1. `parseCapture` **不解析时刻**：`明天16:00 X` 的标题实测是「16:00 X」
   （`明天` 被吃成日期、`16:00` 留在标题里）。所以这里播种刻意不写时刻。
   ⚠️ `e2e/tests/timeline-p2.spec.ts` 用的正是 `明天16:00 …`，
   它的夹具标题里一直带着这段"没被吃掉的 16:00" —— 归 R4 那条线，不在本批动。
2. rail 的名字气泡（`.ht-rail__label`）落在内容区左上。它是 **tooltip 的常规行为**
   （`pointer-events: none`，挡不住点击），**不是产品缺陷** —— 但它会盖住证据图里
   第一行的日期，本目录这张的**第一版**就被压着（`timeline-rework-light.png` 同一处）。
   ⇒ 现在截图前挪开指针并等淡出走完。**证据图要能读，这件事是判据的一部分。**

## 看图看出的两件事（断言没报的）

1. **两张成品图里那条竖条都不是主蓝，这是对的，不是缺陷。**
   浅色卡上是浅灰、暗色卡上是更深的暗色 —— 源码 `packages/ui/src/countdown/EventBoard.tsx:641`
   写的是：`card.template === undefined` 时用 `color.surface-sunken`（"没选过模板"的沉底色），
   选了模板才用 `categorySlotToken(...)` 的分类色。本用例的夹具**没有选模板** ⇒ 图里就该是沉底色。
   登记在这里是为了让下一个人不必再怀疑它，也说明：**这一批的证据图没有一张是"选了模板"的卡**，
   分类色那条路径由 `packages/ui/tests/category-model.spec.ts` 钉着，但没有出图级证据。
2. **`还有 28 天` 与 `11月1日` 互相自洽**（今天是 10-04，差 28 天）。
   这条不在任何断言里 —— 它是"数字与日期是不是同一次算出来的"这个真问题的免费交叉验证，
   只有**看图**才会去做。断言只验了字节数与零出站。

## 与 §7 第 82 条的关系

那条讲的是"非空白挡不住错误屏"（窗口截图当内容载体）。本目录刻意**不用窗口截图当内容证据**：
成品图本身（`card-*.png`）是被验对象的字节，`board*.png` 只用来证明"点得到、失败上得了屏"。

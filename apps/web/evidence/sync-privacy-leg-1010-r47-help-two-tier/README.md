## 它**不证明**的三件事

1. **无头载体**（`carrier.headless` 现量）。
2. **这是一趟只选 `help` 一条腿的局部趟** —— 其余四条腿的判据全在 `notJudged` 里（那是装置对"没选腿"的
   显式表达，不是红）。整族读数在同一条线的 r48。
3. **这 6 张是视口图**（该腿没有 `fullPage`）⇒ 375 那一档第四行卡片落在折叠线以下，
   "四行齐不齐"由机读 `helpWrapFourRowsMeasured` 承担，不由这些图承担。
   这与数据面那格登记的"整页图拍不到内层滚动容器里的东西"是同一条射程。

这一趟落点里**一共 8 枚**（`ls` 现量：README + 6 张 PNG + `report.json`），**全部入库，没有漏下的运行期产物** ——
该腿不导出备份文件，所以这一批不像数据腿那样另有 `*-backup.json` / `*-invalid.json` 夹具。
重跑：`HEYTA_RESPONSIVE_LEGS=help HEYTA_WEB_UI_SWEEP_EVIDENCE=<你自己的落点> pnpm verify:web-ui-sweep`。

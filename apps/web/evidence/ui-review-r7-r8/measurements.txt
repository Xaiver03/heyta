R7 / R8 的取证与实测数字
========================

载体：隔离检出（`git worktree add --detach` 到 HEAD）里 `pnpm -r build` 出的
`apps/web/dist`，用 `python3 -m http.server 4331` 静态服务，Chromium headless
（`--no-proxy-server`，locale 钉 `zh-CN`，`colorScheme` 各跑一遍暗/亮）。

⚠️ **不是** `pnpm check:ai-e2e`，**不是** 4318/4319/4320 —— 那会 SIGKILL 另一条会话
正在用的 vite（§7 第 87 条）。也**不是**移动壳：这几张是**桌面载荷**证据。
⚠️ 语言必须钉 `zh-CN`：不钉的话拍出来是英文界面，而"标题比说明还小"这件事
在英文下被 `uppercase` 掩盖掉一半，取证就取不到缺陷本身。

## R7 侧栏组标题 vs 空态（计算样式，`getComputedStyle` 实测）

| 元素 | 改前 | 改后 |
|---|---|---|
| 分组头「清单」 | `11px` / 600 / `foreground-subtle` / `uppercase` / `letter-spacing 0.06em`（裸值） | `14px` / 600 / `foreground-muted` / 无 transform / 档位自带 `-0.084px` |
| 空态主句「还没有清单」 | `16px`（`row-title`）/ 400 / muted | `14px`（`row-meta`）/ 400 / muted |
| 空态补充句 | `12px` / 500 / subtle | 不动 |

改前是 **11 对 16**（说明比标题大 1.45 倍）；改后三条轴（字号·字重·颜色）单调下降。
暗色实测行：分组头 `14px/600/rgb(203,213,225)` → 主句 `14px/400/rgb(203,213,225)`
→ 补充句 `12px/500/rgb(148,163,184)`；亮色同构（`rgb(71,85,105)` / `rgb(100,116,139)`）。

## R8 认证第一屏

| 量 | 改前 | 改后 |
|---|---|---|
| 「继续」上边缘 − 邮箱输入框下边缘 | **4px**（顶 371 / 底 367） | **12px**（顶 432 / 底 420） |
| 服务端地址栏 | 常驻，预填 `heyta-local://app`（壳）/ `http://127.0.0.1:4331`（本次） | 默认不在 DOM，展开「我自己部署」后出现且带预填值 |
| 粘贴登录链接 / 令牌 | 常驻 | 默认不在 DOM，展开「已经有登录链接或令牌？」后出现 |
| 第一屏文案 | 「还没有凭据」+「同步需要服务端签发的访问令牌…」 | 「用邮箱注册或登录」+「下一步会让你设置密码…」 |

面板内垂直节奏逐条实测（`getBoundingClientRect`）：输入框底 420 → 「继续」顶 432 →
底 476 → 第一个二级入口顶 488 → 底 532 → 第二个顶 544。**全部 12px**，
即表单节奏 `space.3` 一条格子，没有新造值。
（图里看着比 12px 松，是因为 `deviceScaleFactor=2` 且每个可点控件高 44px、
文字在控件里垂直居中 —— 那是命中区，不是间距。）

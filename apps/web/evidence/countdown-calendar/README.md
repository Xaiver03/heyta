## 这张图差点没证到东西（登记下来，别删）

第一趟 `year-dot.png` 拍的是**整屏**，而 11 月那张卡在视口外 —— 图里一个点都没有，
DOM 断言却全绿。修法是截图前 `scrollIntoViewIfNeeded()` 并**量**那颗点真的落进视口
（`boundingBox()` 的 y 在 `[0, 视口高]` 内），否则那条"截图且人看过"就只是仪式。
与 §7 第 82 条（"非空白"挡不住错误屏）同族：**图里有那个东西**才是证据。

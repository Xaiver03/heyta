## 这一格里有一条**已知会覆盖**的取证缺陷（登记为 W5-G1，本批没改）

`countdown-board.png` 这个文件名在 `countdown.spec.ts` 里被**两条用例各写一次**：
`:102`（"真点出一条倒数日"，那时屏上是**一张**卡）与 `:191`（"1280px 下两列"，屏上是**两张**卡）。
同一个 `test-results/` 目录、同一个名字 ⇒ **后跑的那条覆盖前一条**，盘上永远只剩两列那张。
上面那张图确实是两列那张（人核对过），所以本目录里这张**只能证两列**，
"点出一条之后屏上长什么样"那张**从来没有常驻过**。
修法方向（属于下一批）：两条用例各写自己的文件名（`countdown-board-one.png` / `countdown-board-two-cols.png`），
而不是给同一枚路径加时间戳 —— 时间戳会让"看图时对不上台账"变成常态。
与 §7 第 82 条不同族，与"共用 test-results 会删掉唯一证据"同族。

## 人打开看过之后，看见了什么

**改前那张**：管理后台 → 调休/补班 → 「已录入的年度」那一行，左边第一格只写着
`2026…` —— 年份后面被一个省略号**整格截断**；中间是 `2025-09-28 03:06 · ops@example.test`，
右边两条 `gov.cn/…2026.pdf` 与 `…make-up-2026.pdf` 各占一枚灰底徽标，最右是红边的「撤销这一年」。
也就是说这一行里**只有年份的开头四个字符**露了出来。

**改后那张**：同一格完整写成 `2026 · 2 天安排 · 国务院办公厅通知`；两条出处徽标换行成两行，
仍然各自可读；右侧「撤销这一年」位置没变。

## 看图才抓到、断言抓不到的两件事

1. 🔴 **我先前把这条缺陷写成"年份被挤没"，看图之后要更正：被截的是整格，不是年份。**
   界面上不是"2026 后面少了点什么"，而是 `2026…` —— `· 2 天安排 · 国务院办公厅通知`
   整段都不在。措辞要跟着改，因为"年份看不见"会引导下一个人只去救年份，
   而真正的判据对象是**那一整格参与不参与布局**（现在的几何判据量的是
   `clientWidth > 100` 与 `scrollWidth − clientWidth ≤ 1`，正是整格）。
2. 改后那两条出处是**完整 URL 原样铺在界面上**，占两行、拥挤但可读。
   这一条**登记不改**：运营者录入时给的就是整条 URL，界面把它原样回显是
   "让她能核对出处"的一部分；改成"来源 1 / 来源 2 + 悬浮展开"会让她看不见自己录了什么。
   取舍写在这里，而不是留给下一个人重新纠结一遍。

## 与 AGENTS §6.2 规定一的关系

这四条里第 4 条（"人必须真的打开那张图看一眼"）在本轮**是唯一**抓到第 1 条的环节：
自动化断言只报"这一格被裁了多少像素"，它不会说"被裁掉的是哪几段内容"，
也不会指出我文档里那句措辞把缺陷说小了。

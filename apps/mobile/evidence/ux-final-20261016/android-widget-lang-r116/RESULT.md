# r116 · 装机态 Android：应用内中英文切换 × 组件读数一致性

对应台账 `docs/plans/product-ux-optimization.md` 的 UX-S9-143 最后一格
（"最终安装包实测中文/英文切换、冷启动/组件独立唤醒一致；不通过改变整个系统语言规避"）。
**本趟只交 Android 那一档**，四端里其余三端见下面「不证」。

## 出处

- 设备：`emulator-5554`（共享载体）。跑前 `ps Axo command | grep -E "verify-mobile|profile-settings"` 为空。
- 被测包：`com.heyta` `versionName=1.0`、`lastUpdateTime=2026-10-16 17:08:39`
  ⇒ 这一枚 APK 是**别线 10-16 下午那趟四端重装**装进去的，不是本线装的；本线不主张它的构建载体，
  只主张"当前装机包在这一趟里的行为"。
- 主检出 `HEAD`：`4e4515fd`（脚本起跑时自取，打在 `run4.txt` 第一行）。
- 装置：`../android-widget-click-r115/widget-data-leg.py` 的 `lang` 段。
  本趟改了三处装置毛病（见末节），改完的跑法是 `run4.txt` 那一趟。
- 数据：**空态卡**（本趟不造数据）。有数据时卡上主要是用户自己写的标题，
  空态那一句才是产品自己的本地化串 —— 所以判语言要用空态。
- 跑法：`python3 ../android-widget-click-r115/widget-data-leg.py emulator-5554 . lang`

- 本趟绑的那枚桌面实例已收掉：`收掉本趟那枚实例之后残留 (0, [], [])`。

## 不证

- 只测了「今日任务」一枚 provider 的空态那一句。**没测**四象限／习惯／专注三枚在英文态的卡内文案，
  也没测有数据时表头与桶名（`四象限` 那枚的桶名是产品文案，不是用户写的）。
- **没测** iOS / macOS / Windows 三端的装机态语言一致性 —— 台账那一格是整个矩阵的，
  本趟只把 Android 那一档换成读数，其余三档照旧开着。
- 真实用户路径上的"组件独立唤醒"是 30 分钟系统定时器
  （`widget_today_info.xml` 的 `updatePeriodMillis="1800000"`）。本趟**没有等那个定时器**，
  而是把 `APPWIDGET_UPDATE` 直接送给 provider。两者进的是同一段
  `BaseWidgetProvider.onUpdate → WidgetRefresh.pushAll`，
  所以"定时器到点自己重画且语言正确"这半句是**由同一段代码推出来的，不是观测到的**。
- 广播**送达**的凭据是"卡从 0 行回到有内容 + `com.heyta` 进程被拉起"，
  **不是** `am` 回的 `Broadcast completed: result=0`（那一句不证明送达）。
  发广播用的是 root adbd（这台模拟器 `id -u` = 0），因为四枚 provider 都是
  `android:exported="false"`（那是刻意的加固，见 manifest 里那段注释）。
- 跨日过期那句「数据已过期，打开 Heyta 刷新」在英文态长什么样，**没测**（要跨零点）。

## 装置事实（这一趟照出来的，四条都改在装置里或写在这里）

1. 🔴 `[㐀-]` **不是** CJK 字符类，是 `{㐀, -}` 两元素类（`-` 紧挨 `]` 就是字面连字符）
   ⇒ 它匹配的是日期里的 `-`，把英文态的 `2026-10-16 · 0/0` 报成"仍带汉字"。
   已入 `docs/reference/environment-traps.md`。
2. 组件卡靠**坐标矩形**过滤文字，而任何一屏上落进那个框的文字都会被当成卡：
   run3 的起点读数读回 `['注册 / 登录', '0']` —— 那是应用的登录页，因为上一步
   `current_app_language` 刚把应用拉到前台。读卡前必须先 HOME 并验前台。
3. 🔴 `focus_owner()` 原来返回**整份** `dumpsys window`：那里面永远列着桌面那个窗口
   ⇒ "前台是不是桌面"这条判据**恒真**（一条永远通过的判据比没有判据更糟，AGENTS §7 元规则第二条）。
   修成只取 `mCurrentFocus` 那一行；修完在"应用正在前台"这个现成状态下当场红
   （`TEETH OK（前台是应用时它红了）`）。已入 traps。
4. `run1.txt` / `run2.txt` / `run3.txt` 是装置自己坏的三趟（语言探针在设置页上找底部 tab、
   起点读数被应用屏污染、CJK 类写错），**保留**是为了这一族的坏法有原文；
   `lang-card-3-after-kill.png` 是 run3 留下的、run4 不再产出的图，已删。
